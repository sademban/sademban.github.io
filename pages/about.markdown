This site is where I keep practical notes from software and infrastructure work.

The posts usually come from something I had to check, fix, publish, or understand: Docker behavior, Jekyll issues, VS Code extension work, GitHub billing details, service status checks, and similar developer problems.

I try to keep the writing direct. If a post depends on documentation, release notes, or outside reporting, I include the relevant links so the details can be checked.

You can find related code on [GitHub](https://github.com/sademban).
